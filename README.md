# STT module — прототип диаризации на Java

В репозитории находится CPU-прототип, который определяет интервалы речи и автоматически относит их к ролям «Кандидат», «Интервьюер 1» и далее. Актуальная инструкция по сборке и настройке IntelliJ IDEA — в [README Java-модуля](server-prototype/java/README.md).

## Что реализовано

| Режим | Что делает |
| --- | --- |
| **browser** | Базовая страница только для диаризации Nemotron/CAM++. Этот старый режим записывает эталон из системного звука. Для полного демо используйте `integrated`. |
| **integrated** | Совместное демо: один смешанный поток Vosk 0.42, роли Nemotron/CAM++, TTS, read-only предварительная подсказка Артёма и Whisper. Однокнопочный запуск IntelliJ описан в [инструкции](server-prototype/java/INTEGRATED_DEMO.md). |
| **live** | Записывает микрофон из консольного приложения: сначала эталон кандидата, затем интервью. |
| **stream** | Подаёт готовый WAV в одну сессию Nemotron последовательными аудиочанками, имитируя поток. |
| **verify** | Сопоставляет сегменты из JSON-диаризации с эталонным голосом и сохраняет проверенный результат в JSON и CSV. |

Для общего демо запустите `Integrated demo (Vosk 0.42 + Whisper + Nemotron)` из IntelliJ. Эталон автоматически записывается около 10 секунд из единого сигнала микрофона и системного звука; затем та же смесь используется для интервью и передаётся как моно PCM 16 кГц. Vosk получает единственный поток с кадрами 160 мс, Nemotron — четыре кадра вместе (640 мс). TTS чередует доступные русские голоса по основным вопросам и сохраняет голос уточнения; его можно отключить для живого интервьюера. После нажатия «Завершить интервью» страница дожидается отчёта и показывает итоговую оценку и разбивку по вопросам. Подробные шаги, сценарий на шесть вопросов, выходные JSON и метрики находятся в [инструкции](server-prototype/java/INTEGRATED_DEMO.md); модели, аудио и результаты прогонов остаются локально.

## Как назначаются роли

1. Nemotron определяет границы реплик и временные speaker ID.
2. CAM++ из 3D-Speaker строит эмбеддинги голосов. Java сравнивает каждый голос с эталоном кандидата и уже созданными группами интервьюеров.
3. При прямом совпадении выше настроенного порога назначается кандидат или существующая группа интервьюера. По умолчанию порог сходства — 0.60.
4. Если прямого совпадения нет, Java может применить уже подтверждённую роль того же Nemotron speaker ID после накопления 2,5 секунды прямых голосовых подтверждений. Если роль ещё не подтверждена, новая группа интервьюера создаётся по реплике с не менее чем 2,5 секунды чистой речи, когда сходство с кандидатом и существующими группами ниже порога.
5. Если ни одно условие не выполнено, сегмент получает метку «Не определено». Он остаётся в JSON, если Nemotron выдал соответствующий сегмент.

Полная схема условий находится в разделе [«Как сейчас проходит одна реплика»](server-prototype/java/README.md#как-сейчас-проходит-одна-реплика). Поле confidence_percent — эвристическая оценка силы решения, а не вероятность правильности. В исходном режиме `browser` STT не подключена; для текста, подсказок и второго прохода служит отдельный режим `integrated`.

## Выходные файлы

Для каждого запуска режимов browser, integrated, live и stream создаются:

- events.jsonl — события обработки в реальном времени или по аудиочанкам;
- segments.json — завершённые сегменты с временными границами, ролью, speaker ID, сходствами и уверенностью;
- summary.json — параметры запуска, счётчики, задержки и итоговый статус.

Режим verify создаёт JSON и CSV с проверенными сегментами.

Режим integrated дополнительно создаёт `stt-events.jsonl`, `timeline-events.jsonl`, `timeline.json` и `integration-summary.json` в той же папке интервью.

## Запуск

Нужны Windows x64, JDK 17+ и Maven 3. Локально подготовьте нативную библиотеку Nemotron, GGUF-модель Nemotron 3 Diarization и ONNX-модель 3D-Speaker CAM++. Файлы моделей, аудио и нативные библиотеки в Git не хранятся и приложением не скачиваются.

Для сборки и запуска откройте проект server-prototype/java/pom.xml в IntelliJ IDEA и следуйте [подробной инструкции](server-prototype/java/README.md#запуск-в-intellij-idea-с-нуля). На этой Windows-конфигурации JDK 23 для Nemotron нужна подготовленная копия SDK; это описано в той же инструкции.

Проверить Java-модуль можно из каталога server-prototype/java:

~~~powershell
mvn test
mvn package
~~~

## Ограничения текущего прототипа

- Browser-режим требует поддерживаемую браузером передачу звука при демонстрации всего экрана. Если браузер не дал системную аудиодорожку, запись не начнётся; после её обрыва интервью завершится с `finished: false` и `capture.stop_reason: "system_audio_lost"`.
- Это локальный прототип, а не готовый серверный API: авторизация и интеграция с основным приложением ещё не добавлены.
- Переполнение ограниченной очереди завершает текущую запись после обработки уже принятых чанков. Восстановление потока после переполнения пока не реализовано.
- Качество ролей на русском языке нужно измерять на большем наборе вручную размеченных интервью.
