# ADR 0001: Локальный CPU worker и loopback HTTP

**Статус:** принято для текущего прототипа.

**Контекст.** Nemotron и CAM++ используют локальные GGUF/ONNX-модели и нативные библиотеки Windows x64. Браузерная страница нужна для демонстрации записи и результатов на той же машине.

**Решение.** Java worker запускает модели локально на CPU, а `BrowserMode` слушает `127.0.0.1:8765`. Модели и записи не скачиваются приложением и не коммитятся в Git. HTTP-маршруты обслуживают страницу демо и описаны в [OpenAPI](../api/openapi.yaml).

**Следствия.** Развёртывание требует подготовленных файлов моделей и совместимых DLL. Контракт не следует считать внешним серверным API: нет управления несколькими интервью, сетевой авторизации и удалённого развёртывания.
