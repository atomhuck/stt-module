# ADR 0002: Единая потоковая сессия и группировка аудиокадров

**Статус:** принято для текущего прототипа.

**Контекст.** Интегрированному демо нужны короткие кадры для реакции интерфейса и Vosk, а Nemotron получает более длинные блоки. Повторное открытие модели или потеря чанка нарушили бы непрерывность времени и speaker ID.

**Решение.** Во время интервью `integrated` отправляет моно PCM16 16 кГц кадрами по 160 мс, базовый `browser` — до 640 мс. `AudioFrames` объединяет четыре последовательных входных кадра для одной сессии `NemotronStream`. Поэтому обычный блок модели в `integrated` длится 640 мс, а в `browser` может достигать 2,56 с. `LiveSession` хранит состояние ролей и пишет результаты по мере обработки. Для анализа ответа `IntegrationBridge` отправляет сервису Артёма только подтверждённую речь кандидата; смешанный поток используется отдельно для Vosk.

**Следствия.** Последовательность кадров обязательна; нарушение порядка возвращает ошибку. При переполнении очереди захват останавливается и отражает потери в результатах, чтобы не скрывать сдвиг временных меток. Предварительная роль может измениться после финальной разметки Nemotron.
