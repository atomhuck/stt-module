# ADR 0004 — Второй проход Whisper вне основного решения

**Статус:** принято.

**Контекст.** Потоковый Vosk быстро даёт гипотезу ответа и позволяет принять решение по паузе. Смешанная русская и английская техническая речь может требовать уточнения текста.

**Решение.** Основной переход интервью и `decision` остаются на Vosk и текущих правилах `InterviewSession`. После фиксации ответа фрагмент PCM отправляется необязательному локальному Whisper по HTTP. Ответ `/transcribe-json` даёт слова и временные метки; при HTTP 404 Java-клиент использует `/transcribe`. Уточнение обновляет отчёт и может породить `refined`, но не задерживает предварительное решение. При завершении ожидание ограничено `interview.whisper-wait-ms`.

**Следствия.** Без Whisper интервью работает на Vosk; при ошибке появляется `whisper_error`. Нельзя описывать состояние `configured` как подтверждение доступности или успешной обработки. Точность и задержку оценивают только живым прогоном на размеченном аудио.
