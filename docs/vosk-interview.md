# Сервис Vosk и интервью

`vosk-stt-demo/` — отдельный Maven-проект внутри общего репозитория. Spring Boot обслуживает страницу простого STT (`/`), страницу интервью (`/interview.html`), два WebSocket-канала и скачивание Excel-отчёта. Для запуска нужны JDK 17, модель Vosk и достаточно памяти для неё. Модель и Python-окружение в Git не входят.

## Отдельный запуск

```powershell
mvn -f vosk-stt-demo/pom.xml package -DskipTests
$env:VOSK_MODEL_PATH = 'D:\models\vosk-model-ru-0.42'
java -jar vosk-stt-demo/target/vosk-stt-demo-1.0.0.jar
```

Запускайте из каталога `vosk-stt-demo`, если используете относительные пути `./reports` и встроенные примеры. Альтернатива — передать абсолютный `--interview.reports-dir`. По умолчанию Spring Boot слушает порт 8080. Откройте `http://127.0.0.1:8080/interview.html`; для простого STT — корень сайта. Отдельный запуск не включает Nemotron/CAM++: здесь аудио распознаётся без проверки роли кандидата.

## Как проходит интервью

Клиент посылает `start` с уровнями, сервер выбирает вопрос и отправляет `question`. После показа или озвучки клиент посылает `ready`; далее бинарные PCM16 16 кГц моно-кадры (обычно около 50 мс) идут в Vosk и детектор конца ответа. Промежуточный `partial` может меняться. По паузе движок рассчитывает покрытие эталона, отправляет `decision` и либо уточняющий, либо следующий вопрос. В течение `graceMs` возобновившаяся речь может вызвать `retract` и отменить решение. `peek` возвращает только предварительную `preview` и не изменяет состояние интервью.

После решения необязательный Whisper получает фрагмент ответа и может прислать `refined` с текстом и словами. Финальный `report` содержит оценки; при включённой выгрузке — ссылку на XLSX. Полный контракт сообщений и порядок вызовов приведены в [WebSocket-справочнике](api/websocket.md). В общем демо `IntegrationBridge` передаёт этому движку только подтверждённую речь кандидата; смешанный поток отдельно идёт в `/ws/stt`.

## Настройки

Основные значения заданы в [application.yml](../vosk-stt-demo/src/main/resources/application.yml). Через переменные `VOSK_MODEL_PATH` и `WHISPER_URL` задаются каталог Vosk и адрес второго прохода; пустой `WHISPER_URL` его выключает. `vosk.sample-rate` по умолчанию 16000. Параметры `interview.end-silence-ms`, `next-extra-ms`, `other-next-extra-ms`, `follow-up-extra-ms` и `grace-ms` задают задержки и окно отмены, `no-speech-timeout-ms` — таймаут молчания, `max-follow-ups` — лимит уточнений. `whisper-wait-ms` ограничивает ожидание при финальном отчёте. `reports-dir` и `report-download` управляют XLSX и ссылкой для скачивания.

Банк вопросов, словарь и произношение можно заменить путями `interview.questions-path`, `interview.glossary-path`, `interview.spoken-path`. Иначе используются ресурсы из `src/main/resources/interview`. Строка `questions.tsv` содержит шесть колонок через табуляцию: уровень, тема, вопрос, эталон, заметки, уточняющие вопросы через `||`. `glossary.txt` использует `вид;имя;вариант1|вариант2`, где вид — `term`, `slang`, `hedge` или `ignore`. Пустые и начинающиеся с `#` строки пропускаются. Для короткого демо используйте [банк из шести вопросов](../vosk-stt-demo/demo/questions-six.tsv) и [сценарий](../vosk-stt-demo/demo/SCENARIO.md).

## Whisper

Установите `pip install -r vosk-stt-demo/tools/requirements-whisper.txt` в отдельное окружение и запустите `python vosk-stt-demo/tools/whisper_server.py --model small --device cpu --compute-type int8`. Модель может скачаться при первом запуске. Для проверки HTTP без модели используйте `--backend fake`. Сервис слушает `127.0.0.1:9000`; HTTP-контракт описан [отдельно](api/whisper-openapi.yaml). `/transcribe-json` возвращает слова с временными метками, а клиент Java при ответе 404 переходит на текстовый `/transcribe`.

## Диагностика

| Симптом | Проверка |
| --- | --- |
| Vosk не загружается | Проверьте каталог `VOSK_MODEL_PATH`, наличие `am/`, `graph/`, память и нативную библиотеку. |
| Нет текста | Проверьте формат PCM16 little-endian, моно, 16 кГц и что клиент посылает кадры после `start`. |
| Нет второго прохода | Проверьте `WHISPER_URL`, порт 9000 и событие `whisper_error`; основной Vosk/анализ работают отдельно. |
| Нет файла Excel | Проверьте `reports-dir`, права записи, `excelError` в `report` и `report-download`. |
| Нет точных ролей | Отдельный сервис Vosk не выполняет диаризацию. Для ролей запускайте общее демо. |
